# Coffee Listing

Aplicação React que apresenta uma coleção de cafés e permite filtrar os produtos
disponíveis no momento.

## Tecnologias

- React
- Vite
- CSS
- ESLint

Os dados são carregados da API pública do DevChallenges.

## Como executar

```bash
npm install
npm run dev
```

Para validar o projeto:

```bash
npm run lint
npm run build
```

## Funcionalidades

- Listagem de cafés;
- Filtro por disponibilidade;
- Estados de carregamento e erro;
- Tratamento de cafés sem avaliação;
- Layout responsivo;
- Filtros acessíveis por teclado e tecnologias assistivas.
